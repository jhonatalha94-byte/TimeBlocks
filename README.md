# مكعبات الوقت (TimeBlocks)

تطبيق Android لتنظيم اليوم بطريقة الـ Time Blocking: يذكّرك بالمهمة، تختار مدتها، ويرنّ عند انتهاء الوقت.

## بناء ملف APK عبر GitHub (بدون حاسوب قوي)
1. أنشئ مستودعًا جديدًا (Repository) على GitHub.
2. ارفع **كل** محتويات هذا المجلد كما هي (بما فيها المجلد المخفي `.github` والملف `app/timeblocks-debug.jks`).
   - الأسهل: من صفحة المستودع ← **Add file ← Upload files** ثم اسحب الملفات والمجلدات.
3. افتح تبويب **Actions** ← سيبدأ «Build APK» تلقائيًا (أو اضغط **Run workflow**).
4. بعد نحو 5 دقائق، افتح آخر تشغيل ناجح ← قسم **Artifacts** ← نزّل `TimeBlocks-apk` (ملف zip فيه الـ APK).
5. انقل الـ APK إلى الهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

كل نسخة جديدة تُبنى بنفس مفتاح التوقيع، فتُثبَّت فوق القديمة دون فقدان المهام والسجل.

## بعد التثبيت (مهم)
يعرض التطبيق شريطًا أحمر لكل إذن ناقص، اضغط «فتح الإعدادات»:
- **الإشعارات**: ضرورية لوصول التذكير.
- **التنبيه بملء الشاشة** (Android 14+): ليظهر التذكير فوق شاشة القفل.
- **تحسين البطارية**: اختر «غير مقيّد». في هواتف Xiaomi / Oppo / Realme / Samsung فعّل أيضًا «التشغيل التلقائي» (Autostart) للتطبيق.

## الميزات
- مهام مجدولة: مرة واحدة، يوميًا، أو أسبوعيًا (أيام متعددة).
- مهمة فورية يبدأ مؤقتها مباشرة.
- شاشة تذكير بملء الشاشة مع أزرار المدة (1، 2، 5، 10… أو مدة مخصصة)، وأزرار سريعة داخل الإشعار نفسه.
- عدّ تنازلي في إشعار دائم مع إيقاف مؤقت / متابعة / إنهاء مبكر.
- رنين واهتزاز عند انتهاء الوقت مع «تمّت ✓» أو «أحتاج وقتًا إضافيًا».
- سجل يومي: المهام المنجزة، الوقت الفعلي مقابل المخطط.
- إعادة جدولة كل التنبيهات بعد إعادة تشغيل الهاتف أو تغيير الوقت.

## التقنيات
Kotlin · Jetpack Compose (Material 3, RTL) · Room · AlarmManager (setAlarmClock) · Foreground Service · GitHub Actions.

## هيكل الكود
| الملف | الدور |
|---|---|
| `Data.kt` | قاعدة بيانات Room: المهام والسجل |
| `Scheduler.kt` | حساب موعد التذكير التالي وضبط المنبهات الدقيقة |
| `TimerStore.kt` | حالة المؤقت الحالي (محفوظة لتنجو من إعادة التشغيل) |
| `TimerService.kt` | الخدمة الأمامية: العدّ، الإيقاف، الرنين، التسجيل |
| `Notifs.kt` | قنوات الإشعارات والإشعارات نفسها |
| `Receivers.kt` | استقبال المنبهات وإعادة الجدولة بعد الإقلاع |
| `MainActivity.kt` | الشاشة الرئيسية: المهام، السجل، النوافذ |
| `ReminderActivity.kt` / `TimeUpActivity.kt` | شاشات ملء الشاشة |
